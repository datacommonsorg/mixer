Resolve place and other entity names (e.g. countries, cities, organizations, schools, food banks) to Data Commons DCIDs. Resolve every entity this way before using it in other tools; never guess DCIDs. For questions about entities contained in a place (e.g. counties of Kenya, cities of the United States, schools in California), resolve only that place and set `child_entity_type_hints`. The result lists only types that entities under the place actually have, at any depth, so do not resolve intermediate regions or individual children to find or confirm them.
