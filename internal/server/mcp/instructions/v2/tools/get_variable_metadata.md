Describe statistical variables from `search_indicators` and the sources that have data for them on entities from `resolve_entities`: each variable's definition, each source's unit, scaling factor, measurement method, observation period, dates and entity coverage, and the details of each dataset they come from (such as its description, license, release frequency and refresh dates). Pass up to 10 `variable_dcids` per call, also with `child_entity_type_dcid`, and the entity arguments you would pass to `get_observations`.

For values (the latest, a given date or range, trends, comparisons), call `get_observations` directly. Call `get_variable_metadata` when the question asks how a variable is defined, which sources, years or frequencies exist for it, or about a dataset (such as its license or update schedule). After a `get_observations` call, call it when picking a different source depends on which entities or years each source covers (`alternative_sources` does not list them), rather than trying sources one call at a time. Do not call it to double-check `search_indicators` or `get_observations` results that already answer the question.

`variables` lists one entry per requested variable in request order with its `name`, `description`, definitional `properties`, and `sources`: one row per source, ranked as `get_observations` ranks sources for `date` 'latest'. Pass a row's `source_id` as `source_override` to `get_observations` to fetch from that source. `earliest_date`, `latest_date` and `observation_count` cover the source's observations for all the given entities combined, and `entities_with_data` lists which `entity_dcids` it has data for. With `child_entity_type_dcid`, rows describe the parent's child entities of that type, `entities_with_data` lists the parent, `observation_count` is null, and the first row can differ from the source `get_observations` picks by default. `note` explains when a variable has no data for the entities. `datasets` describes each dataset once, keyed by the `import_name` its source rows show (several sources can come from one dataset, and datasets without details are omitted); each entry's `properties` describe the whole dataset, not the given entities.
