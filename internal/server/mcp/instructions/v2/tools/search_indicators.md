Find the statistical variables (indicators) and topics that match a concept, or browse the topic hierarchy. Topics group related variables and sub-topics.

- **Search:** pass `query` with one concept. For questions that mention several concepts, make one call per concept; calls can run in parallel. Search matches by meaning, so synonyms and rephrasings of a concept return largely the same results. Results are the closest matches (up to 10 topics and 10 variables, ranked), returned even when none of them fits the concept, so compare their names against the question instead of assuming the first one fits.
- **Browse:** pass `topic_dcids` to see those topics, typically sub-topics from an earlier result's `member_topics` that haven't been returned yet. Omit both `query` and `topic_dcids` to list the top-level topics, e.g. for "what data do you have?".
- **Entities:** with `entity_dcids`, only indicators with data for at least one of the entities are returned, and `entities_with_data` shows which ones. For questions about the world as a whole, resolve "World" and pass its DCID. Omit `entity_dcids` only for questions that are not about specific entities.
- **Child entities:** for questions about the entities contained in a place (e.g. counties of California, schools in a city), pass the place as the only `entity_dcids` and a type from `resolve_entities`' `candidate_child_entity_types` for that place as `child_entity_type_dcid`. Only indicators with data for entities of that type in the place are returned, and `entities_with_data` lists the place. Make one call per place.

Each topic row lists the topic's direct sub-topics (`member_topics`) and its variables (`member_variables`), and `descendant_variable_count` counts the variables at any depth below it, including those under its sub-topics. A row without `member_topics` lists every one of those variables, so there are no others below that topic. A topic's row is the same in search and browse results, so browsing a topic that was already returned gives the same row; the variables below its sub-topics are in the rows of its `member_topics`. A variable's `observation_properties` names the properties that identify its entities when it describes more than one (e.g. a donor and a recipient country). `note` explains empty or unfiltered results.
