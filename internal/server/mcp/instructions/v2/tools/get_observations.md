Fetch numerical observations and source metadata for statistical variables from `search_indicators` on entities from `resolve_entities`.

- **Batching:** pass related variables that share `observation_properties` and all target entities in one call (or parallel calls when above the per-call limits) instead of calling once per entity or variable. Standard single-entity variables (empty `observation_properties` in `search_indicators`, or variables from topic `member_variables`) all use `observationAbout` and can be batched together.
- **Child entities:** for all entities of a type inside a place (e.g. counties of California, schools in a district), pass only the parent place in `entity_dcids` and set `child_entity_type_dcid`; do not resolve or list individual child entities.
- **Multi-entity variables:** when a variable's `observation_properties` in `search_indicators` is non-empty (e.g. `["donor", "recipient"]` or `["observationAbout", "sourceCounty"]`), set `entity_property` to the role constrained by `entity_dcids` (or `child_entity_type_dcid`) and pass any other constrained roles in `additional_entities`. Omit a counterpart role from `additional_entities` to fetch observations across all counterparts.
- **Dates and sources:** primary source selection already considers all available datasets within the requested date window. When comparing entities or variables, check whether returned dates align and fetch a shared date or range if needed. Pass `source_override` only to pin a `source_id` from a prior response's `source_metadata` or `alternative_sources` (for example to align units, measurement methods, or entity coverage).

`entity_metadata` maps every entity DCID appearing in the returned rows to its display name once across the response. `observations` lists one entry per requested variable in request order: `data` holds columns `["observationAbout", "date", "value"]` (or `[<observation_properties...>, "date", "value"]` for multi-entity variables), `source_metadata` identifies the selected dataset (`source_id`, `import_name`, `provenance_url`, `unit`, `scaling_factor`, `measurement_method`, `observation_period`), `alternative_sources` lists other available datasets in rank order (with `entities_found_count` when multiple entities or entity combinations have data), and `note` explains when a variable has no observations for the requested entities or date window. `scaling_factor` is the denominator of a rate or percentage (for example, `value` `28.4` with `scaling_factor` `"100"` means `28.4` per `100`, or `28.4%`; `scaling_factor` `"1000"` means per `1,000`).
